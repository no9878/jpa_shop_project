회원, 상품, 주문 REST API 서버

회원가입부터 상품 검색, 주문까지 처리하는 쇼핑몰 백엔드 API 서버입니다.
동시 주문 환경에서 재고 정합성을 지키는 데 중점을 두었습니다.

API 명세 · 테스트 (Swagger) GitHub

사용 방법

  1. Swagger에서 POST /api/join으로 회원가입
  2. POST /api/login으로 로그인 (같은 브라우저에서 로그인 상태가 유지됩니다)
  3. GET /api/search로 상품 검색
  4. POST /api/order/new로 주문, GET /api/member-orders로 내 주문 확인

상품 등록, 회원 관리 같은 관리자 기능은 관리자 계정이 필요합니다.

기술 스택

Java 17, Spring Boot, Spring Data JPA, Querydsl, MySQL
AWS EC2 · RDS, Nginx, Let's Encrypt, GitHub Actions
